# Check canals and nuclear investment booms

This folder checks the arithmetic behind [the Research Snack](https://researchsnacks.semanticmachines.fyi/2026-11-19-canals-nuclear-investment-booms/).

From the repository root: `uv sync --locked`, then `uv run check.py 2026-11-19-canals-nuclear-investment-booms`.

The offline check rebuilds fourteen CSVs in a temporary folder and compares each with expected/. It needs no key or network. It checks arithmetic from saved attributed facts, not independent source transcription, full national coverage, exact historical peaks or lifetime investor returns. See [METHOD.md](METHOD.md) and [DATA-SOURCES.md](DATA-SOURCES.md).

Code is MIT. Original explanatory text and calculations are CC BY 4.0. Third-party facts retain the source conditions in DATA-SOURCES.md. No source books, PDFs, graphics, transcripts, personal records or full restricted GDP datasets are distributed.
