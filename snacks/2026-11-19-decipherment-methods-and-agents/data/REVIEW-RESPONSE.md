# What changed

The initial snack's deterministic calculation reproduced its inputs, but some inputs and access claims were wrong. Reproduction did not validate those judgements. This revision changes the coded inputs, regenerates all seven tables and four chart sets, and separates already readable languages from undeciphered/partly mapped systems. No ancient-language experiment was rerun.

The regenerated historical split is **9 full / 8 partial / 3 no readable parallel or key**, with **18/20 known linguistic comparators used**. The prior-target code is a different question. The individual source/coding rationales and stage choices are in the CSV and METHOD.
